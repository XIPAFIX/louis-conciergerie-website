# Louis Conciergerie

Site vitrine de Louis Conciergerie : billets pour le tennis, le football, le rugby et les grands concerts.

- Tout le site est dans `index.html`.
- Les réglages (numéro WhatsApp, formulaire) et la liste des événements sont en bas du fichier, dans la partie « À MODIFIER ».
- Les photos personnelles vont dans le dossier `images/`.
